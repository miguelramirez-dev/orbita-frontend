Órbita: gestión de proyectos

Aplicación demostrativa para organizar tareas y entregas de un estudio digital. Los proyectos, el equipo y los contactos son ficticios. No representa experiencia laboral ni un cliente real.

El problema

Un equipo necesita localizar tareas, conocer responsables y prioridades, y revisar entregas desde el escritorio o el teléfono.

La solución

Una SPA con tablero, lista, resumen y equipo. Permite crear, editar, eliminar y cambiar el estado de las tareas. Los filtros se combinan y las métricas se calculan desde los registros actuales.

Correspondencia con la vacante

  • HTML semántico: navegación, secciones, formularios y tablas.
  • Bootstrap 5.3.3: formularios, botones, tablas y barras de progreso, con diseño propio.
  • JavaScript: eventos delegados, estado, validación, filtros y persistencia.
  • SPA: vistas por hash, navegación sin recarga e historial del navegador.
  • Accesibilidad: etiquetas, foco visible, enlace de salto, diálogo nativo, anuncios de estado y controles por teclado.
  • Diseño responsivo: tablero de cuatro, dos o una columna según el espacio disponible.
  • API REST: GET a JSONPlaceholder con validación de respuesta, tiempo límite, carga, error y reintento.

Decisiones y límites

Las tareas se guardan únicamente en localStorage del navegador. El directorio REST se consulta en Equipo y no almacena contactos. No hay backend de tareas, autenticación propia ni colaboración entre usuarios. Bootstrap, iconos y fuentes están incluidos localmente. Solo el directorio REST requiere conexión.

Recorrido para una entrevista

  1. Crea una tarea y muévela a revisión.
  2. Filtra por proyecto y prioridad, y cambia a lista.
  3. Recarga para comprobar la persistencia local.
  4. Abre Resumen y explica cómo se calculan los indicadores.
  5. Consulta el directorio en Equipo. Desconecta la red y repite para mostrar el error y el reintento.
  6. Recorre los controles con Tab y cierra el formulario con Escape.

Esta implementación incluye medidas de accesibilidad, pero no constituye una certificación WCAG. La integración REST es de lectura; las operaciones de tareas son locales.
